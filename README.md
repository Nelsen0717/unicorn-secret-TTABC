### 1️⃣ Hero 首頁區
- 楊正大博士簡介

- 視覺吸引的大標題與CTA按鈕
- 滾動提示動畫

### 2️⃣ 創業征途時間軸
從2004到2020年的完整創業歷程，包括：
- 2004：創業起點，確立收費與客戶保護政策
- 2008：大數據部門成立
- 2010：五人團隊進軍中國大陸
- 2012：A輪融資1億美金估值
- 2015：成為獨角獸（10億美金估值）
- 2016：姚明代言
- 2019：出售給中國平安
- 2020：正式退休返台

### 3️⃣ 獨角獸心法一圖流 ⭐ NEW
- **視覺化精華圖表**：完整呈現獨角獸3-2-1特質法則
- **3大挑戰**：挑戰傳統、挑戰自我、挑戰不可能
- **2大面向**：解決人生大問題 + 面向一個大市場
- **1心1意**：核心團隊要用年輕人
- **反直覺原則**：低價等於低價值、客戶問題就是我們的問題
- **PDF下載**：提供完整純文字筆記下載連結

### 4️⃣ 核心創業心法
- **收費機制的抉擇**：Quality Leading vs Cost Leading
- **客戶保護政策**：偏袒客戶是職責
- **速度至上**：一快吃慢的互聯網法則
- **使命必達**：無資源也要創造資源

### 5️⃣ 文化與價值體系
- Know Why > Know How（原則大於規則）
- 數據驅動決策
- 流程視覺化（從1D到2D討論）
- 為價值而堅持，不為和諧而妥協
- 空椅子哲學（客戶永遠在場）
- 科學精神（拒絕虛詞）

### 6️⃣ 管理智慧
- **人才管理**：4P選才標準（正直、企圖心、智商、正能量）
- **人才不齊線**：每週必須interview
- **破格用人**：打破薪資表限制
- **用年輕人**：給機會犯錯成長
- **薪酬哲學**：對人才慷慨，對事情嚴格
- **領導原則**：培養接班人、從錯誤中找自己責任

### 7️⃣ 決策思維
- **以終為始**：目標倒推 + 趨勢預判
- **猶豫不決 > 做錯決定**
- **富人思維 vs 窮人思維**
- **無限資源思維**：先定義完美解法
- **成本重新定義**：機會成本 > 時間成本 > 金錢成本
- **小事化大**：今天的小問題是明天的大災難

### 8️⃣ Lessons Learned (10大教訓)
1. 人的問題 = 企業的全部問題
2. 學習是成為優秀企業家的唯一途徑

4. 中國大陸市場的挑戰
5. 客戶信任比短期利潤重要
6. 速度 > 完美
7. 對人才慷慨，對事情嚴格
8. 先人後事，但堅決不妥協

   ```bash
   # 如果有Git倉庫
   git clone [repository-url]
   
   # 或直接下載文件
   ```

2. **打開項目**
   ```bash
   cd unicorn-masterclass
   ```

3. **啟動本地服務器**

   ```bash
   # Python 3
   python -m http.server 8000

   ```

   ```bash
   npx http-server -p 8000
   ```
   
   方式三：使用VS Code Live Server擴展
   - 安裝 Live Server 擴展
   - 右鍵點擊 index.html
   - 選擇 "Open with Live Server"

4. **瀏覽網站**
   ```
   打開瀏覽器訪問：http://localhost:8000
   ```

也可以直接雙擊 `index.html` 文件在瀏覽器中打開，但建議使用本地服務器以確保所有功能正常。

## 🔧 自定義指南

### 修改配色
編輯 `css/style.css` 中的 CSS 變量：
```css
:root {
    --primary-color: #YourColor;
    --secondary-color: #YourColor;
    /* ... 更多顏色 */
}
```

### 調整動畫速度
修改 CSS 變量：
```css
:root {
    --transition-smooth: all 0.3s ease; /* 改為你想要的時間 */
}
```

### 更改圖表配色
編輯 `js/main.js` 中對應圖表的 `backgroundColor` 和 `borderColor`。

### 添加新內容
1. 在 `index.html` 中添加新的 section
2. 在 `css/style.css` 中添加對應樣式
3. 如需互動，在 `js/main.js` 中添加JavaScript
